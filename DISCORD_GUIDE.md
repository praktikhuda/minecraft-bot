# 🎮 Panduan Penggunaan Bot Minecraft Server

Selamat datang di Server! Kami memiliki bot Discord khusus untuk mempermudah permainan dan manajemen server. Bot ini menggunakan **Slash Commands** (/), jadi kamu tinggal ketik garis miring dan pilih perintahnya.

## 🟢 Perintah Umum (Bisa Dipakai Semua Pemain)
- **/status**: Cek apakah server sedang menyala atau mati, serta melihat daftar nama pemain yang sedang *online* di dalam game.
- **/info**: Mengecek status performa mesin server (penggunaan CPU, sisa RAM, dan durasi server menyala).
- **/tps**: Mengecek skor TPS (Ticks Per Second) untuk mengetahui apakah server sedang lag atau berjalan mulus.
- **/ip** (atau /join): Menampilkan alamat IP Publik yang bisa kamu gunakan untuk masuk ke dalam server Minecraft.

## 💬 Fitur Spesial: Cross-Chat
Kamu tidak perlu membuka Minecraft untuk mengobrol dengan pemain di dalam server! Cukup kirim pesan di channel Discord khusus ini, dan pesanmu akan **langsung muncul di layar Minecraft** pemain lain!

---

## 🛠️ Perintah Admin (Hanya untuk Admin Discord)
Perintah ini dikunci dan tidak bisa digunakan oleh member biasa demi keamanan.
- **/start & /stop & /restart**: Untuk menyalakan, mematikan, atau menyegarkan ulang server.
- **/backup**: Mengompres (ZIP/TAR) seluruh dunia Minecraft dan menyimpannya sebagai cadangan aman.
- **/logs**: Menampilkan 15 baris terakhir dari mesin terminal server (sangat berguna untuk mengecek error/crash).
- **/wl [nama]**: Menambahkan pemain baru ke daftar putih (Whitelist) agar mereka bisa masuk ke server.
- **/kick [nama] & /ban [nama]**: Menendang atau memblokir pemain yang bermasalah.
- **/say [pesan]**: Mengirim pesan pengumuman raksasa (Broadcast) ke seluruh pemain di dalam server.
- **/op [nama] & /deop [nama]**: Memberikan akses operator Minecraft penuh ke seseorang.

*Bot ini dirancang untuk menjaga server tetap aman dan menyenangkan! Jika bot tidak merespons, silakan hubungi Admin.*
